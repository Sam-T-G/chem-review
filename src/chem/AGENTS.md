# src/chem/: the chemistry engine (team chem)

The rules of Lewis structures and VSEPR as pure functions over plain data. Every module uses it. It imports nothing
from React, the DOM, Three.js, modules or screens.

## Files
- `structure.ts`: a Lewis structure as plain data, and the moves a student can make on it.
- `elements.ts`: element facts and shell rules. The numbers come from `elements.data.json`.
- `elements.data.json`: generated by `scripts/gen-elements.mjs`. Never edit it by hand.
- `solve.ts`: the reference structure for one center atom, found by trying every bond combination. Holds `DEFAULT_CONVENTION`.
- `assess.ts`: what is still wrong with a drawing, in the order a student should fix it.
- `vsepr.ts`: counts the electron groups around the center atom and names the shape.
- `repulsion.ts`: the 3D model, with electron groups pushing apart on a sphere.
- `layout2d.ts`: where things sit in the flat drawing. Geometry only.
- `problems.ts`: the guided problems in teaching order. Learning design reviews changes to it.

## Read first
- `docs/chemistry/sources.md`: where each rule and number comes from, the conventions, the known gaps.
- The comment at the top of the file you are changing.

## Rules
- C1 Plain TypeScript only: no packages, and no imports from outside this folder. `pnpm check:repo` enforces it. [D-0004]
- C2 Every rule has a test whose expected answer is written from the textbook, never from what the code returns. Write the test first. [D-0004]
- C3 A new fact or number gets its source in `docs/chemistry/sources.md` in the same change. No citations on screen.
- C4 Functions are pure. A move returns a new structure and never changes the one it was given.
- C5 Formal charge decides between drawings, and period 3 atoms may expand. Changing `DEFAULT_CONVENTION` is Sam's decision. [D-0005]
- C6 Never hand a module an angle measured from the repulsion model to print. Angle text comes from the shape table or the two measured angles in `vsepr.ts`. [D-0008]
- C7 The repulsion strengths must keep the textbook arrangement lowest for all 13 shapes. `tests/vsepr.test.ts` checks it.
- C8 Modules depend on what these files export. Renaming or removing an export means changing every caller in the same change and naming that module's team as reviewer.

## Check your work
- `pnpm exec vitest run assess layout problems solve structure vsepr`: the six engine test files, a few seconds.
- `pnpm verify` before you call it done.

## Update when you change this
- A rule, a source, a convention or a gap: `docs/chemistry/sources.md`.
- The problem list or its order: `docs/learning/guided-steps.md`, with learning as reviewer.
- A choice between conventions: a decision record.
- A new file here: the list above.
