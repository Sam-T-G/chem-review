# D-0011: The atoms' faces lose their googly eyes and follow a Fall Guys look

- Status: accepted
- Date: 2026-11-13
- Decided by: Sam
- Teams: design, lewis, shell

## Context
The redesign (D-0010) gave each atom a face. The first eyes were white circles with dark pupils that followed the pointer. Sam's reaction:

> i think the googly eyes are a little creepy, can we go for like a fall guys aesthetic

## Decision
The googly eyes go. The atoms' faces follow the look of Fall Guys characters.

## Consequences
- Design's reading of that look, which Sam has not seen yet: a pale patch on the ball with two tall, solid dark eyes set close together, without whites or pupils, the pair leaning a little toward the pointer. `docs/design/look-and-motion.md` describes it.
- The same face is drawn three ways (in 3D on the board, in CSS in the panel and the tray, with native views on the home screen), and all three follow that doc.
- If Sam's reaction to the new drawing changes the direction, it gets a new record.
- Characters in later modules start from solid eyes (M-0002).
